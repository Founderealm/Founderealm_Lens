# Security

Report a security problem privately, not in a public issue: on this repository's
[Security tab](https://github.com/Founderealm/Founderealm_Lens/security), choose
**Report a vulnerability**. Founderealm answers there.

What the plugin runs, writes and fetches is in the [README](README.md#where): a binary
from this repository's releases, checked against the SHA-256 the plugin carries, and
grammars from this repository's grammar collection releases, checked against their manifest. It never runs the
repository's code and never sends its contents anywhere.
